השאלה

קראו את השאלה בעיון. בעמודים הבאים נפתור אותה סעיף אחר סעיף.

נתונה המחלקה SmartPhone. למחלקה 3 תכונות:

  • דגם המכשיר – model מטיפוס String
  • נפח אחסון / זיכרון בג׳יגה – storage מטיפוס int
  • מחיר בשקלים – price מטיפוס double

  1. ממשו את המחלקה SmartPhone. מימוש המחלקה יכלול את כותרת המחלקה ותכונותיה.

  2. כתבו פעולה פנימית במחלקה SmartPhone בשם upgradeStorage. הפעולה תקבל כפרמטר קוד שדרוג (int code), ותעדכן את גודל הזיכרון של הפלאפון ואת מחירו בהתאם לכללים הבאים:

    • אם הקוד הוא 1 – הזיכרון יוגדל ב-128 ג׳יגה-בייט, והמחיר יגדל ב-200 ש״ח.
    • אם הקוד הוא 2 – הזיכרון יוגדל ב-256 ג׳יגה-בייט, והמחיר יגדל ב-400 ש״ח.
    • אם הקוד הוא 4 – הזיכרון יוגדל ב-512 ג׳יגה-בייט, והמחיר יגדל ב-800 ש״ח.
    • עבור כל קוד אחר – לא יבוצע שינוי בזיכרון ובמחיר.

  3. כתבו פעולה חיצונית (הנכתבת במחלקה הראשית Main) בשם upgradeStorage. הפעולה תקבל כפרמטרים עצם מסוג SmartPhone וקוד שדרוג (int code), ותעדכן את גודל הזיכרון של הפלאפון ואת מחירו בהתאם לאותם כללים בדיוק:

    • אם הקוד הוא 1 – הזיכרון יוגדל ב-128 ג׳יגה-בייט, והמחיר יגדל ב-200 ש״ח.
    • אם הקוד הוא 2 – הזיכרון יוגדל ב-256 ג׳יגה-בייט, והמחיר יגדל ב-400 ש״ח.
    • אם הקוד הוא 4 – הזיכרון יוגדל ב-512 ג׳יגה-בייט, והמחיר יגדל ב-800 ש״ח.
    • עבור כל קוד אחר – לא יבוצע שינוי בזיכרון ובמחיר.

שלב 2 מתוך 5 · סעיף א׳

סעיף א׳ – כתיבת המחלקה

כותרת המחלקה והתכונות שלה.

נזכיר את סעיף א׳:

ממשו את המחלקה SmartPhone. מימוש המחלקה יכלול את כותרת המחלקה ותכונותיה.

מה כותבים בבחינה?

בבחינה, ובבחינת הבגרות, בסעיף כזה כותבים רק את כותרת המחלקה ואת התכונות שלה. אין צורך לכתוב:

  • פעולה בונה
  • פעולות מאחזרות (get)
  • פעולות קובעות (set)
  • פעולת toString

כל תכונה מוגדרת עם מילת הגישה private, הטיפוס והשם, ולידה תיעוד בעברית שמסביר מה התכונה מייצגת.

הפתרון לסעיף א׳

public class SmartPhone
{
    private String model;     // דגם המכשיר
    private int storage;      // נפח אחסון בג'יגה-בייט (GB)
    private double price;     // מחיר המכשיר בשקלים
}

הפתרון המלא של המחלקה

בבחינה אין חובה לכתוב את החלקים האלה, אבל כך נראית מחלקה שלמה בתוכנית אמיתית. פתחו כל חלק בנפרד.

פעולה בונה

הפעולה הבונה נקראת בעת יצירת עצם חדש עם new. היא מקבלת ערכים ומאתחלת בהם את התכונות. שמה זהה לשם המחלקה, ואין לה טיפוס החזרה.

    // פעולה בונה: יוצרת עצם חדש ומאתחלת את התכונות
    public SmartPhone(String model, int storage, double price)
    {
        this.model = model;
        this.storage = storage;
        this.price = price;
    }
פעולות מאחזרות (get)

התכונות הן private, ולכן קוד מחוץ למחלקה אינו יכול לקרוא אותן ישירות. פעולה מאחזרת מחזירה את ערך התכונה. יש אחת לכל תכונה.

    // מחזירה את דגם המכשיר
    public String getModel()
    {
        return this.model;
    }

    // מחזירה את נפח האחסון בג'יגה-בייט
    public int getStorage()
    {
        return this.storage;
    }

    // מחזירה את מחיר המכשיר בשקלים
    public double getPrice()
    {
        return this.price;
    }
פעולות קובעות (set)

פעולה קובעת משנה את ערך התכונה לערך שהתקבל כפרמטר. היא אינה מחזירה ערך, ולכן טיפוס ההחזרה שלה הוא void.

    // קובעת את דגם המכשיר
    public void setModel(String model)
    {
        this.model = model;
    }

    // קובעת את נפח האחסון בג'יגה-בייט
    public void setStorage(int storage)
    {
        this.storage = storage;
    }

    // קובעת את מחיר המכשיר בשקלים
    public void setPrice(double price)
    {
        this.price = price;
    }
פעולת toString

הפעולה מחזירה מחרוזת שמתארת את העצם. היא נקראת אוטומטית כשמדפיסים עצם עם System.out.println.

    // מחזירה מחרוזת שמתארת את המכשיר
    public String toString()
    {
        return this.model + " | " + this.storage + "GB | " + this.price + " NIS";
    }
המחלקה בשלמותה 
public class SmartPhone
{
    // ===== תכונות =====
    private String model;     // דגם המכשיר
    private int storage;      // נפח אחסון בג'יגה-בייט (GB)
    private double price;     // מחיר המכשיר בשקלים

    // ===== פעולה בונה =====
    public SmartPhone(String model, int storage, double price)
    {
        this.model = model;
        this.storage = storage;
        this.price = price;
    }

    // ===== פעולות מאחזרות =====
    public String getModel()
    {
        return this.model;
    }

    public int getStorage()
    {
        return this.storage;
    }

    public double getPrice()
    {
        return this.price;
    }

    // ===== פעולות קובעות =====
    public void setModel(String model)
    {
        this.model = model;
    }

    public void setStorage(int storage)
    {
        this.storage = storage;
    }

    public void setPrice(double price)
    {
        this.price = price;
    }

    // ===== toString =====
    public String toString()
    {
        return this.model + " | " + this.storage + "GB | " + this.price + " NIS";
    }
}

שלב 3 מתוך 5 · סעיף ב׳

סעיף ב׳ – פעולה פנימית

פעולה שנכתבת בתוך המחלקה SmartPhone ופועלת על העצם שזימן אותה.

נזכיר את סעיף ב׳:

כתבו פעולה פנימית במחלקה SmartPhone בשם upgradeStorage. הפעולה תקבל כפרמטר קוד שדרוג (int code), ותעדכן את הזיכרון ואת המחיר:

  • קוד 1: זיכרון +128, מחיר +200
  • קוד 2: זיכרון +256, מחיר +400
  • קוד 4: זיכרון +512, מחיר +800
  • כל קוד אחר: ללא שינוי
הצג את הפתרון

הפעולה נכתבת בתוך המחלקה SmartPhone. היא אינה מקבלת עצם כפרמטר, כי היא פועלת על העצם שזימן אותה. לכן היא ניגשת ישירות לתכונות באמצעות this.

    // פעולה פנימית: משדרגת את נפח האחסון ואת המחיר לפי קוד השדרוג
    public void upgradeStorage(int code)
    {
        if (code == 1)
        {
            this.storage = this.storage + 128;   // זיכרון גדל ב-128 GB
            this.price = this.price + 200;       // מחיר גדל ב-200 ש"ח
        }
        else if (code == 2)
        {
            this.storage = this.storage + 256;   // זיכרון גדל ב-256 GB
            this.price = this.price + 400;       // מחיר גדל ב-400 ש"ח
        }
        else if (code == 4)
        {
            this.storage = this.storage + 512;   // זיכרון גדל ב-512 GB
            this.price = this.price + 800;       // מחיר גדל ב-800 ש"ח
        }
        // קוד אחר: לא עושים כלום
    }

נקודות חשובות

  1. הפעולה היא void: היא משנה את העצם ואינה מחזירה ערך.
  2. הפרמטר היחיד הוא code. העצם שמשתנה הוא זה שנמצא לפני הנקודה בזימון.
  3. אין else אחרון, כי עבור קוד אחר לא קורה דבר.

איך מזמנים את הפעולה?

קודם יוצרים עצם בתוכנית הראשית, ואז מזמנים עליו את הפעולה: שם העצם, נקודה ושם הפעולה.

הצג הדגמת זימון בתוכנית הראשית 
public class Main
{
    public static void main(String[] args)
    {
        // שלב 1: יצירת עצם מסוג SmartPhone
        SmartPhone phone = new SmartPhone("Galaxy S24", 128, 3500.0);

        // שלב 2: הדפסת העצם לפני השדרוג
        System.out.println(phone);

        // שלב 3: זימון הפעולה הפנימית על העצם (שם העצם + נקודה)
        phone.upgradeStorage(2);

        // שלב 4: הדפסת העצם אחרי השדרוג
        System.out.println(phone);
    }
}
הפלט:
Galaxy S24 | 128GB | 3500.0 NIS Galaxy S24 | 384GB | 3900.0 NIS

קוד השדרוג 2 הוסיף 256 ג׳יגה-בייט לזיכרון (128 + 256 = 384) ו-400 ש״ח למחיר (3500 + 400 = 3900).

סעיף ג׳ – פעולה חיצונית

פעולה שנכתבת במחלקה Main, מחוץ למחלקה SmartPhone, ומקבלת את העצם כפרמטר.

נזכיר את סעיף ג׳:

כתבו פעולה חיצונית (הנכתבת במחלקה הראשית Main) בשם upgradeStorage. הפעולה תקבל כפרמטרים עצם מסוג SmartPhone וקוד שדרוג (int code), ותעדכן את הזיכרון ואת המחיר לפי אותם כללים בדיוק (קוד 1: ‎+128 ו-‎+200, קוד 2: ‎+256 ו-‎+400, קוד 4: ‎+512 ו-‎+800, קוד אחר: ללא שינוי).

הצג את הפתרון

הפעולה נכתבת בתוך Main, לכן אין לה גישה ישירה לתכונות הפרטיות של SmartPhone. היא קוראת אותן בעזרת פעולות מאחזרות ומשנה אותן בעזרת פעולות קובעות. הפעולה static כי היא נקראת מתוך main בלי עצם של Main.

    // פעולה חיצונית: משדרגת את נפח האחסון ואת המחיר של העצם שהתקבל
    public static void upgradeStorage(SmartPhone phone, int code)
    {
        if (code == 1)
        {
            phone.setStorage(phone.getStorage() + 128);   // זיכרון גדל ב-128 GB
            phone.setPrice(phone.getPrice() + 200);       // מחיר גדל ב-200 ש"ח
        }
        else if (code == 2)
        {
            phone.setStorage(phone.getStorage() + 256);   // זיכרון גדל ב-256 GB
            phone.setPrice(phone.getPrice() + 400);       // מחיר גדל ב-400 ש"ח
        }
        else if (code == 4)
        {
            phone.setStorage(phone.getStorage() + 512);   // זיכרון גדל ב-512 GB
            phone.setPrice(phone.getPrice() + 800);       // מחיר גדל ב-800 ש"ח
        }
        // קוד אחר: לא עושים כלום
    }

נקודות חשובות

  1. העצם מועבר כפרמטר, ולכן השינויים שהפעולה עושה נשמרים בעצם המקורי, גם בלי להחזיר ערך.
  2. אי אפשר לכתוב phone.storage, כי התכונה פרטית. משתמשים ב-getStorage() וב-setStorage().
  3. אפשר לתת לפעולה החיצונית אותו שם כמו לפנימית, כי רשימות הפרמטרים שונות.

איך מזמנים את הפעולה?

יוצרים עצם בתוכנית הראשית, ואז שולחים אותו כפרמטר לפעולה, יחד עם קוד השדרוג. אין נקודה ואין שם עצם לפני שם הפעולה.

הצג הדגמת זימון בתוכנית הראשית 
public class Main
{
    public static void main(String[] args)
    {
        // שלב 1: יצירת עצם מסוג SmartPhone
        SmartPhone phone = new SmartPhone("Pixel 9", 256, 3200.0);

        // שלב 2: הדפסת העצם לפני השדרוג
        System.out.println(phone);

        // שלב 3: זימון הפעולה החיצונית - שולחים את העצם וקוד שדרוג
        upgradeStorage(phone, 4);

        // שלב 4: הדפסת העצם אחרי השדרוג
        System.out.println(phone);
    }

    // כאן נכתבת הפעולה החיצונית upgradeStorage מהפתרון למעלה
}
הפלט:
Pixel 9 | 256GB | 3200.0 NIS Pixel 9 | 768GB | 4000.0 NIS

קוד השדרוג 4 הוסיף 512 ג׳יגה-בייט (256 + 512 = 768) ו-800 ש״ח (3200 + 800 = 4000).
